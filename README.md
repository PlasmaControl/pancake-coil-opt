# Pancake Coil Optimization (rebuild)

A from-scratch rebuild of [pancakecoilopt](https://github.com/PlasmaControl/pancakecoilopt),
a Python package for optimizing HTS (high-temperature superconducting) pancake
coils. Being rebuilt incrementally, module by module, to relearn the codebase.

## Getting started

```bash
uv sync
uv run pytest
```
